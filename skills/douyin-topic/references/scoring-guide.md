# 潜力分评分规则（douyin-topic skill）

双系列各自独立排名，**跨系列分数不可比**——成功指标不同：
- 🔥 热度系列看**播放量**（蹭热点、跟得快）
- 📈 涨粉系列看**关注转化 / 垂直度**（建账号定位）

## 公式

```
潜力分 = 0.4×热度 + 0.3×垂直匹配 + 0.2×竞争度(反向) + 0.1×互动
```

每项 0–100，缺失字段记**中性 50**（不奖不罚，避免缺数据话题被误杀）。

## 各分项口径

| 分项 | 权重 | 算法 | 注意 |
|------|------|------|------|
| 热度 | 0.4 | 系列内按最大热度值归一化；上升榜 +15 | 热度系列用 `view_count`/`hot_value`，涨粉系列用 C 源 `viewNum`（仅作相对活跃度，**不是播放量**） |
| 垂直匹配 | 0.3 | 命中关键词数：3+=100 / 2=80 / 1=60 / 0=0 | 英文大小写不敏感子串匹配 |
| 竞争度(反向) | 0.2 | `100 - min(100, video_count×8)` | 话题内视频数越多分越低 |
| 互动 | 0.1 | `min(100, discuss/view × 5000)` | 讨论数/播放比；缺字段中性 |

## 关键口径（踩过的坑，勿回退）

1. **C 源 viewNum 量级小**（程序员→2506、ai绘画→55603），疑似视频数而非播放量 → **只当「方向内存在性」信号**。若把 C 源热度与 A/B 热榜混用，会因量级差把涨粉系列全压成低分 → 涨粉系列**系列内单独归一化**（`c_max`），否则全系列平铺在 53 分附近无法排序。
2. **系列内归一化**：热度用 `hot_max`（热榜最大值），涨粉用 `c_max`（C 源最大值）。跨系列不可比。
3. **无命中诚实输出**：`no_hit.hot=true` + 已尝试关键词，不硬凑低分话题充数。
4. **上升榜加分**：A 源 `sub_board == "rising"` 加 15，代表上升趋势。

## 结果字段

每条话题输出 `score / heat / match / comp / inter` 五项 + `matched_keywords`（命中的方向关键词），便于人工复核「为什么这条排前面」。
