# 潜力分评分规则（douyin-topic skill）

双系列各自独立排名，**跨系列分数不可比**——成功指标不同：
- 🔥 热度系列看**播放量**（蹭热点、跟得快）
- 📈 涨粉系列看**关注转化 / 垂直度**（建账号定位）
- 💥 低粉爆款代理榜是涨粉池的**横切展示维度**（换个排序），不改潜力分公式

## 公式

```
潜力分 = 0.4×热度 + 0.3×垂直匹配 + 0.2×竞争度(反向) + 0.1×互动
```

每项 0–100，缺失字段记**中性 50**（不奖不罚，避免缺数据话题被误杀）。

## 三源合并口径（2026-08-30 扩源）

| 源 | 内容 | boards 标记 | group_id |
|----|------|------------|----------|
| A 热榜（免登录） | 主榜 51 + 上升 5 | main / rising | 有（98%） |
| B 抖音指数（登录态） | 实时热点 90 + 飙升热点 30 | main / rising | 无 |
| C 创作者中心垂类（登录态） | 个性化话题 Top5 | foryou | 无 |

1. **word 归一合并**：同词去重，A 基础记录优先（有 group_id）；hot_value 取最大；view/video/discuss 取第一个非空；`boards` 取并集。
2. **sub_board 代表值**：按 main > rising > foryou 取优先级最高者——主榜词不重复吃 rising +15 加成，但 `boards` 保留完整证据（💥榜看证据不看代表值）。
3. **系列内归一化跨源强制**：B 指数量级（百万~千万）与 A 热榜不同，C 垂类热度更小——热度分只在本系列合并池内归一化（统一 max），**跨源跨系列不直比**（同旧 C 源 viewNum 量级坑，勿回退）。

## 各分项口径

| 分项 | 权重 | 算法 | 注意 |
|------|------|------|------|
| 热度 | 0.4 | 系列内按最大热度值归一化；rising 板证据 +15 | 热度系列用 `view_count`/`hot_value`/B 指数解析值，涨粉系列同池统一 max |
| 垂直匹配 | 0.3 | 命中关键词数：3+=100 / 2=80 / 1=60 / 0=0 | 英文大小写不敏感子串匹配；**C 源个性化条目免关键词直入涨粉系列**（算法个性化=已预过滤），无命中时 match=0 靠其他分项排序 |
| 竞争度(反向) | 0.2 | `100 - min(100, video_count×8)` | 话题内视频数越多分越低；B/C 源缺字段中性 50 |
| 互动 | 0.1 | `min(100, discuss/view × 5000)` | 讨论数/播放比；缺字段中性 |

## 💥 低粉爆款代理榜（2026-08-30 新增）

```
lowfan = 0.5×heat + 0.5×comp    （仅 boards 含 rising 的条目参与）
```

- **为什么是代理**：官方低粉爆款榜已随巨量算数 2026-01 升级为抖音指数而从 web 端下线；话题详情页（视频级）需 trendinsight 独立 SSO，未接。
- **信号逻辑**：rising 板证据（A 上升榜 / B 飙升热点）= 话题处于上升期，新内容有机会被推；comp 高（话题内视频少）= 低粉号竞争得过来。两者相乘近似「小号吃流量」的机会度。
- **展示**：独立成榜（≤8 条），markdown 标注「代理信号」口径，输出时必须保留该标注，不得暗示是官方低粉爆款数据。
- **视频级明细**：走三方人工清单（蝉妈妈/飞瓜/新榜，全登录墙，禁 CLI 不进管线）。

## 关键口径（踩过的坑，勿回退）

1. **C 源量级坑**（历史教训，现用于 B/C 源）：不同源热度数值量级差异大，若跨源直比会把整系列压成低分 → **系列内单独归一化**是铁律。
2. **系列内归一化**：热度用合并池系列内最大值。跨系列不可比。
3. **无命中诚实输出**：`no_hit.hot=true` + 已尝试关键词，不硬凑低分话题充数。C 源个性化条目进涨粉系列属于「有候选」，不算无命中。
4. **rising 加分**：boards 含 rising 的条目（A 上升榜 / B 飙升热点）+15，代表上升趋势；经 sub_board 代表值去重后每词最多吃一次。
5. **B/C 源失败降级**：解析为空 / 登录态缺失 → notes 记原因，仅 A 源出选题，不中断不硬凑。

## 结果字段

每条话题输出 `score / heat / match / comp / inter` 五项 + `matched_keywords`（命中的方向关键词）+ `sources`（来源 A热榜/B指数/C垂类）+ `boards`（板证据并集）+ `personalized`（C 源个性化直入标记）；💥榜条目额外带 `lowfan`。便于人工复核「为什么这条排前面」。
