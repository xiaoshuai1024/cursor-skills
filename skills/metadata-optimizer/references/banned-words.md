# 事实边界硬规则（候选判废清单）

> 两道词库的分工：
> - **本文件**管「素材里没有的不能说」——事实边界。候选命中 = 该候选直接判废，换下一个。
> - **platform-compliance 的 word-list.md**（blog-src `.agents/skills/platform-compliance/references/word-list.md`）管「平台不允许说什么」——合规红线（诱导/极限词/结构红线）。它由 `make check-compliance` 与 metadata-lint 强制执行。

## 事实边界（〔qiaomu〕事实边界硬规则 + 本仓 no-fabrication 铁律）

素材（fact card）中不存在的事实时，候选**不得出现**：

- **时新性声明**：刚刚 / 最新消息 / 突发 —— 素材里没有明确时间锚点就不用
- **首创性声明**：首个 / 全球第一 / 业内首个 / 史上最
- **权威背书**：Nature / Science / 具体榜单名 / 具体奖项 —— 素材没提就不挂
- **具体规模数字**：用户数 / 融资金额 / 榜单排名 —— 只用 fact card 里核过的数字
- **受众规模断言**：百万人在用 / 人手一份

**兜底规则**：素材整体干瘪（无硬数字、无权威、无冲突）→ 只出克制档（L1）候选，不硬凑钩子。宁可标题平，不可事实假。

## 结构红线（与 lint RED_LINE_PATTERNS 同步，命中即 FAIL 拒发）

| 类别 | 词 | 替换方向 |
|------|----|---------|
| 胜负宣言 | 打赢 / 吊打 / 碾压 / 完胜 / 击败 | 改数据陈述：「账单差一倍」「分数打平」 |
| 挑衅反问 | 凭什么 | 改中性问句：「为什么」「差在哪」 |
| 官方口吻 | 重磅通知 / 重要通知 / 紧急通知 / 即日起 / 全面实施 / 正式实施 | 去公告腔，用平铺句式 |
| 绝对化 | 杀疯了 / 最强 / yyds / 绝绝子 / 封神 | 换具体数字或事实 |

## 平台侧禁忌补充（research.md §1.4）

- 公众号标题党五类（2024-05 官方）：混淆官方 / 煽动蛊惑 / 夸大误导 / 冒充公众人物 / 对抗审核
- 清朗 2025-07 点名「一标题多框架」（同标题配不同内容误导）
- 巨量引擎：绝对化用语（最 / 第一 / 100%）+ 虚假悬念诱导影响审核
- 标题党反噬路径：高打开 → 低完读 → 算法判低质 → 降权 + 信任透支
