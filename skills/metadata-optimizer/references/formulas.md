# 标题公式库（候选生成时的档位与句式）

> 来源标注：〔qiaomu〕= qiaomu-xinzhiyuan-title（2688 篇新智元标题统计驱动）；〔toolkit〕= social-creator-toolkit；〔实证〕= 中文平台数据研究（小红书 Top50 / 公众号 A/B 等，见 blog-src `openspec/changes/metadata-optimization/research.md` §1.2）。
> 本账号线上的真实历史标题举例用〔本仓〕标注。

## 五档位公式（每个候选必须归档，同档位不重复出）

| 档位 | 公式 | 例（来源） |
|------|------|-----------|
| 数字型 | `<实体> <动作> N 个 <结果单位>` / `N <单位>里的<钩子>` | 「TypeScript 教父开源 21 万 Star 的 25 个 Agent Skill」〔本仓〕；「6 个 skill 让它自动剪视频」〔本仓〕 |
| 问句型 | `<你><痛点场景>？<因为/答案钩子>` | 「你安装 Harness 总失败？因为忽略了这 3 个源码级细节」〔本仓 video-generation SKILL.md〕 |
| 反差型 | `还在 X？Y 才是 Z` / `X 不再是 Y，而是 Z` | 「AI 编程还在玩 Prompt 工程？Harness 工程才是下一个方向」〔本仓〕；「你装的 Claude Code 早不是脚本了，307MB 二进制里的真相」〔本仓〕 |
| 后果型 | `不 X 就 Y`（损失厌恶）/ `看完省 N 小时` | 「装完 Codex 只会写代码？6 个 skill 让它自动剪视频」〔本仓，问句+后果复合〕 |
| 克制型 | `<实体>：<平铺事实>`，无情绪词 | 「Claude Code 上下文压缩机制拆解」〔本仓风格〕——素材干瘪时的默认档〔qiaomu〕 |

**档位强度三档**〔qiaomu〕：克制 L1 / 默认 L2 / 爆炸 L3。**L3 仅当素材真有 breaking 级事实**（顶级开源、重大版本、极端数字），否则用 L2；素材整体干瘪默认只出 L1。

## 7 心理触发（候选自检：至少命中 2 个）〔toolkit〕

画饼（更好的愿景）/ 损失厌恶（不做会亏）/ 数字（可预期）/ 反认知（打破常识）/ 提问（对号入座）/ 参照物（和已知物对比）/ 圈定人群（「前端」「写 Go 的」）。

## 小红书 10 句式〔toolkit〕（用于 标题_小红书 变体）

亮点前置+悬念 / 别再[错误做法]了 / 后悔没早点[动作] / [人群]必看 / [数字]个[结果] / 救命！[痛点] / 有手就会[动作] / [工具]隐藏用法 / [人群]请进 / 一秒搞定[事]。

**注意**：小红书避感叹号（句式里的「救命！」等按平台禁忌降级为 `|` 或去掉），核心词放前 10 字。

## 简介首句（2 秒留存门）〔higgsfield social-hook〕

首句 = 当前不适 → 更好愿景 → 行动路径 三拍〔marketingskills Human Action Model〕。例：「每次配权限都要查文档？（不适）这篇拆完你会有一张权限决策图（愿景）跟着 6 步走（路径）」。

## "Now you can" 测试〔marketingskills〕

标题前默念 "看完这个视频/文章，你现在可以 ____"。空填不出来（既不 compelling 也不 true）→ 候选作废；填得出但标题没体现 → 把能力写进标题。
