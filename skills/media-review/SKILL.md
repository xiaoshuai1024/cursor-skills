# Media Review — 内容转化潜力评审（问题分级 + 三轮清零）

**定位**：排期后、发布前的最后一道内容门禁，覆盖**视频成片**与**公众号文章**两条资产线。只回答两个问题：①这篇内容**合格吗**（能发吗）②**能不能保持较高转化**（预估播放/打开/收藏/关注落在哪）。本 skill 是评审与判定——写稿归 talkshow/blog-writing、采集归 video-analytics/wechat-analytics、台账归 video-pipeline-tracker、发布归 video-generation/wechat-publishing、发布后运营归 post-publish-ops。

> 方法论首跑：2026-09-04 九支排期视频三轮评审（openspec `media-review-skill`），砍 1 留 8。基线数值随 `data/analytics/diagnosis.json` 与快照滚动更新，勿写死在稿里。

## 何时用

- 排期视频批量评审（发布前体检）/ 单支「能不能发」「值不值得救」
- 数据平淡后判断：救（润色/重渲）还是放弃（撤卡腾槽）
- 新片在库提排期前的潜力预估

## 选题预测-优化循环（1 万线门禁；2026-09-04 用户定规：预测达标才算选题完成）

触发：选题期「这个题值不值得做」/ douyin-topic Phase 1 选题确认前。四步：

1. **初筛**：六维速打分（0-5×6，家族基线取「目标形态」的家族，时效维看热点斜率）。<18/30 直接改角度，不进预测。
2. **预测**：六维产出预估播放区间，**证据链 = 家族基线 × 对标实绩 × 热点斜率**，每一维的分数必须能指出依据。**抖音家族基线首版口径（2026-09-05 快照实读建档，71 条在册）**：破万仅见于「具名热门产品/项目 + 工具价值/反直觉机制揭秘」族（DSH 系 12k~29.7k）；抽象方法论/概念/人设叙事族天花板 ≈1,900（中位 ≈1,000）；脱口秀人设情绪标题族 0~226。**族判错 = 预测直接不达线**：弱族选题先按四杠杆改造（首选绑具名产品实体/换搜索型形态），改造不动即放弃，不耗满 3 轮迭代。族内角度同判：「反直觉机制+你受影响」（DSH 记忆机制 22.3k）对「复盘/取舍流水账」（DSH 九月链 986→78 衰减）——同族差近 300 倍，角度先于风格。**预估中位数 ≥10,000 = 选题完成**，出速评卡（六维得分 + 预估区间 + 证据链 + 一句判语）贴 douyin-topic 立项记录 / `make topic-funnel` 登记。
3. **迭代**：中位数 <10,000 → 按四杠杆改方案后重新预测：① **绑热点**（接入冲刺窗口，见下节——窗口内家族基线上修）② **换搜索型形态**（教程/清单/排坑/对比，吃搜索长尾）③ **强化收藏钩**（备查卡/公式/决策树前置到标题与置顶评论）④ **标题重钩**（工具全称 + 数字反差，对照 hit-patterns 句式榜）。**迭代上限 3 轮**；3 轮仍 <10,000 → 选题放弃，或用户拍板降级为「配菜槽」（低预期标注，不占黄金主力档心智）。
4. **反灌水**：禁止为过线虚报——校准回路 +7d 回查每支实绩，虚高预测按 miss 复盘追责到维度，同一口径累计虚高 2 次即在下批评审强制下调。

立项本身仍走既有必问门禁——预测达标是选题工作的完成标准，不是发布放行。

**日更与门禁位次（2026-09-07 用户定规：保持日更 + 严格审核预估流量）**：每日一更 20:00 档节奏不变（发布红线 1，用户所有），但档期内容必须三选一，**禁止弱族新题凑数硬发**：① 新题过 1 万线门禁（本节流程）；② 已验证爆款族（具名热窗载体）的系列深化续作——同族按本节预检过线后投产，pilot 制不变；③ 播放 ≥5,000 题材的同题加拍（7-12d 转化判断联动）。无过线新题当日按 ②→③ 补位；常青配菜槽降为兜底位（②③ 均不可用才轮到，低预期标注不变）。数据依据：2026-09-07 涨粉结构复盘——25 支在册视频涨粉九成集中于 DSH 源码深拆家族 top3（+141/+124/+121，合计占总播放 65%），离开该系列后一周日更净涨粉 ≈0（+5/+2/0/+2/-1）；非过线新题对涨粉目标贡献趋零（详见 `data/video-pipeline/media-review/2026-09-07-cadence-gate-retro.md`）。

## 公众号浏览量预估门禁（2000 线；2026-09-05 用户定规：预估达标才算排期完成）

触发：公众号文章挂卡/群发确认前（R2 出预估区间时同步执行）；草稿箱存量稿在下次排期前补测。四步：

1. **预测**：`预估中位 = 送达地板（送达×10%）+ 家族基线中位 × 六维修正系数（六维均分÷2.5，钳 0.5~2.0）`。证据链三件必留，缺一不算完成预测：**送达基数**（发表记录 `appmsgpublish?sub=list` 的 sent_status 实查，涨速随日更快照更新）、**家族基线**（wechat-analytics 已发样本按形态分层聚合，2026-09 首版口径：工具清单/榜单型 ~2000、纪律/框架型 ~413、小众工具源码拆解型 ~180、原理科普 evergreen 无样本按拆解 ×1.5，随快照季度重算）、**六维打分**（与视频同一张六维表）。预估必给区间，不给点估。
2. **门禁**：预估中位 **≥2,000 = 预估完成**，进挂卡/群发确认流程；**<2,000 → 修改优化循环**。
3. **迭代**：按四杠杆改稿后重测：① **绑热点** ② **换搜索型形态**（教程/清单/排坑/对比——公众号家族基线的决定项；家族差距靠润色补不上，差距 ≥3 倍时只有换形态一条路）③ **强化收藏钩**（模板/速查表/命令清单写进摘要承诺位）④ **标题重钩**（首行 ~30 字出钩 + 工具全称 + 数字反差），顺手做 P0 合规清零（`check-compliance` HIGH=0 是同轮硬前置）。**迭代上限 3 轮**；3 轮仍 <2,000 → 上抛用户拍板：低预期标注发 / 撤卡换稿 / 不排期持牌，禁止第 4 轮，禁止为过线虚报。
4. **反灌水与校准**：预估发布确认后经 `make calibration ARGS="add …"` 登记 calibration.jsonl（机制见「预估校准回路」）；公众号爬坡慢，**+7d 只记斜率、+30d 定案**；实绩低于区间下界 50% = miss-高估，追责到维度，同一口径累计虚高 2 次强制下修该家族基线。

边界：本门禁是排期工作的完成标准，**不替代群发确认**（群发仍属必问红线）；粉丝基数小（百位级）时推荐流量是阅读主力，预估的重心永远在家族基线不在送达数。

## 热点冲刺模式（1 万线的主力达成路径）

**雷达判据**（日循环手动触发，红线 9 禁无人值守定时）：douyin-topic 三源扫当期热点，命中条件 = `热点斜率陡（实时+飙升双榜） × 工具长尾价值（可搜索、可持续产出） × 与账号定位匹配`。命中即触发冲刺编排（DSH 剧本，2026-08 实测产出 4 支破 7k）：

| 时点 | 内容 | 吃什么流量 |
|---|---|---|
| D+0 | 安装/上手教程（抢先发） | 搜索首波 |
| D+2 | 插件清单/踩坑 | 搜索长尾 + 收藏 |
| D+5 | 源码深度解析（长视频高密度） | 推荐 + 收藏 |
| D+7 | 事故/复盘/对比 | 站队互动 + 搜索 |

48h 快反窗口沿用 douyin-topic 既有定规（确认当天下大纲、次日渲染、第三天内挂定时；超窗放弃赶窗）。冲刺期选题自动过 1 万线预检（热点窗口内家族基线上修），窗口外选题按常规预测。

## 问题分级（先分级，再谈修）

| 级 | 定义 | 处置 |
|---|---|---|
| **P0** | 红线阻断：合规违禁词、队列双卡、非黄金档（非 20:00）、无封面、AI/原创声明缺失、登录态失效、本地 schtasks 兜底任务失控、公众号**群发未经确认**、发布链路静默缺陷（如 background 简写被过滤、原文链接丢失） | 不处置 = blocked；执行见「砍卡与撤卡 SOP」 |
| **P1** | 转化硬伤：3s/15s 钩子缺失（视频）或标题摘要无钩（文章）、无收藏钩、知识点不达标（见深度维度）、家族基线翻车、同题撞车、标题无热词 | 修或砍，不许带病上槽 |
| **P2** | 转化优化项：追更链缺失、置顶评论/留言无承接、标题可再升级、节奏拖（视频超 180s 主力档、文章段落超 4 行） | 顺手修，不阻塞 |
| **P3** | 备忘：数据时效风险（新闻/价格/版本类）、平台规则变动观察 | 记录进报告，投产前复核 |

## 三轮清零退出（硬上限 3 轮，防无限润色）

- **R1 转化漏斗审查**：视频逐支过六关——3s 钩子 / 15s 兑现 / 中段流失风险 / 收藏钩 / 关注转化 / CTA 单动作；文章逐篇过六关——标题摘要打开钩 / 首段承诺兑现 / 中段弃读风险（段落节奏、小标题密度）/ 收藏在看钩 / 关注+原文导流 / 留言互动引导。产出逐支逐篇 P0-P3 问题单 + 首轮标旗。
- **R2 内容质量矩阵 + 基因压力测试**：按下方检查项总表过机检组/深度组/梗含量组（视频）或公众号特色组（文章），再做六维打分 + 预估数据区间 + 槽位经济学。**R2 强制对标实抓**：用 douyin-topic `search_works.py` 按本支核心搜索词实抓 2-3 个当期同类高赞作品，提取标题结构/封面 hero/前三秒钩子做对照——仿结构与密度、不仿句子（版权与同质化双红线）；对标卡（作品链接 + 可借鉴结构点）贴进报告；无登录态/无网络时降级用 `references/hit-patterns.md` 基因库对照并在报告注明。本轮出砍/留终判。
- **R3 终审与执行**：终版日历、砍卡执行（必问门禁）、润色落地、遗留风险清单。
- **清零退出**：某一轮不再新增 P0/P1 → 收口出报告；3 轮打满仍有 P0/P1 → 该篇放弃或 blocked，上抛用户，禁止第 4 轮（评审的边际收益在 3 轮后归零，犹豫本身就是「潜力不足」的证据）。

## 检查项总表（聚合各 skill 既有 checklist，只引用权威源头，不另立标准）

### 机检组（可执行门禁，逐条跑）

| 检查项 | 权威 skill | 执行 | 判级 |
|---|---|---|---|
| 去 AI 味（L1 绝对禁词 / L2 慎用 / 有机生长隐喻禁词：长成了、长在文件里、从事故里长） | de-ai-smell | `make check-ai-smell path=<稿>` | 命中 = P0 |
| 违禁词/平台红线（广告法极限词、诱导、导流、权威冒用、收益承诺） | platform-compliance | `make check-compliance`；梗不豁免（「遥遥领先」「吊打」类梗本身就是违禁词） | 命中 = P0 |
| 标题/简介/话题元信息（七项清单、30 字当量、平台变体） | metadata-optimizer | `make metadata-lint` | 不合格 = P1 |
| 色彩可读性/封面（对比度门禁、自定封面在片） | video-generation | `make video-lint` / `make video-cover-check` | 失败 = P0 |
| 文章链路终检（若评到配套长文） | article-quality-check | `make article-check slug=<slug>` | 按其门禁 |

### 深度与获得感组（本 skill 新增维度，无既有机检，人工判定）

| 检查项 | 口径 | 判级 |
|---|---|---|
| 知识点数量 | 每支 ≥3 个可独立成立的知识点（机制/判据/数字/命令各算一类）；≤2 个 = 单薄 | 不达标 = P1 |
| 知识点深度 | 到**机制层**（有数字/受控对照/源码行为支撑，如「144:1 输入输出比」），不落到**现象层**（如「token 费很多」）；现象复述 = 不算知识点 | 不达标 = P1 |
| 获得感 | 观众能带走 ≥1 件可执行物：命令 / 公式 / 清单 / 决策树（收藏钩的本质；置顶评论承接） | 缺失 = P1 |
| 水文门 | 连续两卡无硬信息 = 水文，返工补实料，禁凑情绪空转 | 命中 = P1 |

### 梗含量组（**仅视频**；缺省档 = 超级炸场 + 职场自嘲，标准以 talkshow 为权威）

⚠️ 文章链路是**严肃档缺省、脱口秀点名制**——未点名的文章不查笑点密度，只查去 AI 味与合规；点名脱口秀的文章按本组口径验收。

| 检查项 | 口径 | 判级 |
|---|---|---|
| 笑点密度 | ≥2.5 笑点位/卡（逐卡数，报告里列明细） | 不足 = P1（写稿链返工）或 P2（成片不可改时降档声明） |
| 禁区零玩笑 | 数据陈述句 / 结论 / CTA / 签名句出现玩笑 = 掉信任 | 命中 = P1 |
| 职场梗边界 | 自嘲位只打「我 / 我的系统 / 我的 agent」；不打真实雇主/同事/平台；怨气不进数据句与结论 | 越界 = P0（下架风险） |
| 真实锚定 | 每个梗挂真实机制/事故/约定，编造行为换笑点 = 违规 | 命中 = P1 |
| 热梗时效 | 联网核当期热梗保质期（牛马/精神离职/词元类）；过期梗进 R2 新鲜度维扣分 | 过期 = P2 |

### 结构组（口播三要素，权威 = video-generation）

提问式开头（≤20 字问句）/ 钩子埋设必逐一回收 / BGM+音效+转场齐备；结尾四段 CTA 与签名句固定。缺 = P1。

### CTR 专项组（推荐流第一转化位）

| 检查项 | 口径 | 判级 |
|---|---|---|
| 封面 hero | ≤8 字、三秒可读、带张力（悖论/反差/禁令式）；参照基因库 hero 榜（每步都合理/全绿最危险/就是不做/全员无辜） | 超 8 字或无张力 = P2；缺封面 = P0（发布红线） |
| 标题候选 | 每支 ≥3 候选、跨钩子原型（悬念问句/数字反差/身份共鸣/后果警告），按「热词+悬念数字」两维打分排序 → metadata-lint 收口 → 人选定稿；只有单候选无对比 = P2 | 无候选对比 = P2 |
| 平台变体 | 抖音 ≤30 当量含工具全称；B站可带系列 tag（如【DSH源码拆解】）；公众号首行 ~30 字出钩；搜一搜/搜索关键词落标题或摘要首句 | 缺变体 = P2 |

### 公众号文章组（权威 = blog-writing `references/wechat-retention.md` + wechat-publishing + wechat-analytics）

| 检查项 | 口径 | 判级 |
|---|---|---|
| 打开钩三件套 | 标题（首行 ~30 字内出钩，悬念/数字/身份钩；公众号语境≠抖音 30 字硬限）+ 摘要（承接标题给承诺，不与标题重复）+ 封面（头图信息量） | 缺钩 = P1 |
| 留存结构 | 段落 ≤4 行 / 小标题节奏（连续 1500 字纯文字必断）/ 收尾结论式散文（blog-writing 硬规矩） | 违反 = P1 |
| 发布配置四查 | 标题/摘要(digest)/封面（2.35:1 头图 + 1:1 次图）/原文链接，四项按 wechat-retention 口径逐查 | 缺 = P0 |
| 发布链路坑 | background 简写被过滤、代码高亮失效、原文链接未注入、内链替换失败（wechat-publishing 已踩坑位），群发前预览验证 | 命中 = P0 |
| 原文导流 | 「阅读原文」是公众号唯一站外转化位：必须指向博客长文（baseURL/posts/<slug>/），正文尾部有配套视频块则核对 link-map 渲染 | 缺失 = P1 |
| 关注与互动钩 | 开头/结尾引导关注位 + 结尾互动问题 + 留言承接预案（发布后置顶留言/作者回复） | 缺 = P2 |

**文章转化指标源**：`data/wechat-analytics/`（五级漏斗：送达→打开→读完→互动→关注与原文导流；打开率/读完率/分享率分位看 diagnosis 与 snapshots）——打开归标题摘要封面、读完归结构节奏、转化归导流位，三层分开归因后再下问题单。

## 六维打分表（R2 用，每维 0-5；视频与文章同一张表）

1. **工具热词**：标题/开场含可搜索工具全称（吃搜索+推荐双流量；文章看标题与 H1）
2. **收藏钩**：清单/公式/决策树/备查卡（头部收藏率 1.2~2.0%，账号中位 1.18%；文章对应「收藏/在看/原文导流」位）
3. **悬念数字**：具体数字反差（如 178 全绿 vs 当场崩）
4. **系列生态**：合集挂载/追更联动/编号连续性（文章=专辑 tag 与系列互链）
5. **家族基线**：同形态历史表现——**最重的一票**，用快照聚合勿凭印象（2026-09 口径：抖音 DSH 源码系 419~4.5k，职场脱口秀系 0~226；公众号看 wechat-analytics 分位）
6. **新鲜度**：新闻/价格/版本类内容的半衰期，发布日口径复核

**判例**：热词 ≤2 + 生态 ≤1 + 家族基线翻车，三维同时不及格 → 放弃，无论沉没成本多少（2026-09-04 native-solo 判例：预估 300~800 播放、重改最贵）。

## 槽位经济学（每日一更红线下）

砍一支的价值 = 空槽机会成本 − 平庸片负资产。空槽前先盘点回填候选（成片在库的 backlog，按六维表快速打分）；没有更强候选时，「平庸胶水片」（系列生态 5/5）优于空槽。回填挂卡 = 发布动作，必问。

## 系列分段投产与常青资产线定位（2026-09-05 用户定规，openspec prediction-staged-production）

**实证口径（抖音 7d 即终局）**：timeseries.db 18 支序列完整视频实读，+7d 后播放增长全部 1.00~1.04 倍（P30≈P7，数值 SSOT 在 prediction-model.json `horizon_note`/`p30_p7_multiplier`）——**抖音不建 30d 对账窗口，长期口径在抖音不产生新信息**；非爆款内容 48~72h 即见终局（d1≈终值），爆款第一周仍在爬。公众号线维持 +7d 斜率 / +30d 定案双窗口不变（爬坡特性不同）。

**系列分段投产**：≥3 集的系列选题一律先产 **pilot 1 集**（热窗冲刺内容 pilot+第 2 集），发布后走 48h 哨兵 + 7d 对账，**达线才批量投产剩余集数**；pilot 未达线 → 系列降配菜或砍，产能回填 backlog（判例：DSH 11 集一次投产，ep1 拿 22.4k 后 ep2-11 合计 <6k、6 支 0 播放，分段制在第 2~3 集即可止损约 8 集产能）。热窗冲刺 D+0/D+2/D+5/D+7 编排本身就是分段制，不受影响。

**常青资产线定位**：常青/搜索型内容（排坑/清单/对比/教程）在抖音只挣首发一周的量——无长尾复利（2026-09-05 实证），1 万线唯一达线路径仍是具名热窗载体；其主战场是**公众号（2000 线，双窗口）与博客 SEO（唯一真搜索长尾资产）**，抖音侧定位**配菜槽**：低预期标注、不占主力档心智，20:00 档位次降为兜底（无热窗日先以爆款族续作/同题加拍补位，均不可用才轮到配菜槽，2026-09-07 位次定规）；配菜视频冷启动失败不触发救片加码（认赔归档即可），系列批量判断以公众号 + B站数据为主。

## 砍卡与撤卡 SOP（放弃判定的执行；必问门禁，用户当场授权后执行）

1. **抖音**：`py -3.11 scripts/pub/douyin_scheduled_dedup.py delete <标题关键词> <时间子串>`——双条件（标题+时间）定位，卡片时间是「2026年09月12日」中文格式；删完自动重扫复核到 0。⚠️ 勿用 `douyin_delete_scheduled.py`（按标题关键词会连保留卡一起删，有误删前科）。
2. **快手**：`py -3.11 scripts/pub/kuaishou_delete_scheduled.py <关键词> 0`（保留条数 0 = 全删匹配卡）。
3. **B站**：先查 `content/link-map.json`——pending 状态即无卡；已挂卡用 `py -3.11 scripts/pub/bilibili_delete_video.py <bvid>`。
4. **本地 schtasks 兜底直发任务必删**：任务名见 link-map 各平台字段（如 `sph-w1-<slug>-<日期>`），`schtasks //delete //tn <任务名> //f`。⚠️ 不删它，平台卡砍了照样到点自动发（2026-09-04 实录：原定 09-12 19:50 自动直发视频号）。
5. **视频号平台卡**：受登录态约束（失效 errCode 300333），撤不了列 HUMAN 待扫码，报告里挂账。
6. **撤后回写**：复核到 0 的扫描输出 + 截图落 `.tmp/`，台账 `vpt stage`/备注收敛，评审报告记执行链。

## 发布后哨兵与救片（评审闭环；手动触发，红线 9 禁无人值守）

每支评审判「保留」的视频，发布后进入哨兵期，挂进日循环（`make next` 开屏带跑）：

| 节点 | 查什么 | 阈值（2026-09 首版口径，随校准回路修正） |
|---|---|---|
| +1h | 播放起步、置顶评论已挂、粉丝群已推、官方活动/话题生效 | 任一转化位缺失 → 立即补（post-publish-ops） |
| +24h | 冷启动判定 | 抖音 24h 播放 < 300 = 冷启动失败；3s 跳出 > 60% = 开头问题；收藏率 < 0.5% = 收藏钩失效 |
| +7d | 对账 + 转化判断（并入 make next 既有 AUTO 项） | 见「预估校准回路」 |

**救片动作清单（按症状，平台编辑页可改，不需撤卡）**：冷启动失败 → 换封面 hero + 编辑页改标题 + 话题重挂；开头流失 → 置顶评论补「30 秒版结论」+ 粉丝群带钩推送；收藏钩失效 → 置顶评论补备查清单。救后回看 24h：仍无起色 = 认赔归档、选题漏斗回落，不再加码。**撤卡重发仍属必问门禁**；改标题/封面后必须平台侧复核生效。

## 预估校准回路（让推测越用越准；机检闭环 openspec prediction-calibration-loop，2026-09-05）

- **登记**：每支「保留」判定的预估区间（六维打分产出）在发布确认后必须入账——`make calibration ARGS="add --slug <slug> --line video|wechat --publish <发布日> --pred <低>~<高> --family <族>"`。
- **对账全自动**：到期项（视频 +7d 定案——2026-09-05 实证 7d 即终局，见「系列分段投产」节，不设 30d 窗口 / 公众号 +7d 记斜率、+30d 定案）由 `make next` 提示 AUTO，执行 `make calibration` 自动取数（timeseries.db / 公众号快照）并判定：落区间 = hit；低于下界 50%+ = miss-高估；高于上界 50%+ = miss-低估；带内偏出 = 近区间软判定（不进追责计数）；**达线预测实绩未兑现门禁线强制 miss-高估**（1 万线/2000 线同规）。
- **miss 复盘人写**：`make calibration ARGS="set --slug <slug> --review '哪个维度打错了：家族基线过乐观 / 新鲜度漏判 / 钩子高估'"`——结论必须人写、追责到六维维度，写后 `make next` 对应 ASK 消失。
- **SSOT**：台账 = `data/video-pipeline/media-review/calibration.jsonl`（`calibration.md` 是生成视图勿手改）；参数 = `prediction-model.json`（家族基线/门禁线/对账窗口/系数钳位的唯一数值源，本文件散文只写口径）。
- **优化出口**：聚合报告输出命中率、MAPE、分家族 bias（实绩/预估中位中位数）与 miss 计数；**同家族同向 miss ≥2 → 基线下修/上修建议（×bias）**——改 `prediction-model.json` 属必问 ASK，改后同步本文件散文并注日期。
- 口径沿革：**2026-09-04 起 1 万线目标口径**（达线但实绩未破万按 miss-高估复盘）；**2026-09-05 起公众号 2000 线口径**（+7d 记斜率、+30d 定案，miss 复盘同样追责到维度）；等权起步，**≥20 支对账样本前不引入加权模型**；家族基线随快照季度重算（聚合报告季度跑一次承接口径）。
