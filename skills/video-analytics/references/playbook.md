# 创作技巧库（playbook）

> 每条技巧有 ID / 触发条件 / 具体做法 / 验证指标。`va/coach.py` 按账号真实数据把技巧装配成 directives（`data/analytics/directives.json` + `reports/directives.md`），video-generation 写下一支脚本前必读。
> 技巧依据：行业调研（research 见 openspec research.md §2 + 2026-08-24 增补搜索）+ 本账号实测。行业口径：3 秒内划走 72-75%、前 3 秒留存占完播权重 ~40%、好钩子提升前 3 秒留存 +19%（蝉妈妈）、每 5-10 秒一个信息点、系列化是知识类涨粉第一杠杆。

## H 前段留存（0-15s，钩子）

| ID | 技巧 | 具体做法 | 验证指标 |
|----|------|---------|---------|
| H1 | **结论前置** | 最反常识/最有争议的结论放第 1 句口播 + 首屏字卡。抖音官方建议「最精彩部分放开头」；铺垫句（"这条视频带你…"）全部删除或压到结论之后 | 平均停留时长（目标：从 <15s 提到 30s+） |
| H2 | **首帧 = 结果画面** | 封面帧与视频第 0 帧直接展示「成果物」（跑通的界面/对比数据/代码图），不做标题静态页 | 3s 退出率（B站 crash_rate / 抖音深度） |
| H3 | **数字具体化** | 开头数字必须具体且反差（「307MB」「133 个插件」「差一倍」），禁「很多/大量/几个」。实测口径：《剪辑技巧》式名词开头比《教你剪辑》完播高 2.3 倍 | 平均停留时长 + 完播率 |
| H4 | **痛点提问 + 数据反差** | 「问你一个问题/你有没有想过」后 10 字内接数据反差（80% 的人只听过 X，但实际上 Y） | 前 15s 深度 |
| H5 | **删过渡句** | 第 2-3 句常是「这条视频带你拆完 X」「先看它的结构」类过渡——它们正是平均观众离开的位置（实测：4/4 视频停在第 2-6 句的过渡句上）。过渡信息改为字卡/画面承担，口播直接进下一个论点 | 平均停留句位（retention.avg_stop.sentence_no 后移） |

## M 中段留存（完播）

| ID | 技巧 | 具体做法 | 验证指标 |
|----|------|---------|---------|
| M1 | **每 5-10 秒一个信息点** | 分镜按「论点配额」写：每个口播论点 ≤2 句（≈10s），到点必须换论点/换画面/换视觉焦点 | 完播率、观看深度 |
| M2 | **波峰刺激** | 论点切换处配 SFX/字卡弹出/BGM 情绪档变化；埋钩子的回收时刻配专属音效（对齐三要素的回收视觉强调） | 完播率 |
| M3 | **压铺垫删冗余** | 中段每 30s 自查一次「这 30s 删掉观众损失什么」；答案为空即删。快剪/变速处理操作演示 | 完播率 |
| M4 | **章节化/拆系列** | 单支 >3min 且完播 <1% → 拆集（一集一个点）或压到 2min 内；B站保留长版（完播权重低） | 完播率 + 系列追更 |

## C 涨粉转化（核心目标）

| ID | 技巧 | 具体做法 | 验证指标 |
|----|------|---------|---------|
| C1 | **结尾预告下一集** | 最后 10s 固定「下一集讲 X（比本集更反常识的点）」；下一集开头回收该预告（对齐钩子回收表） | 播转粉率 |
| C2 | **关注价值承诺** | 关注引导不说「关注我」，说订阅理由：「这个系列每周更新 X，关注不迷路」——账号长期价值一句话（配合中性签名口径） | 播转粉率 |
| C3 | **转粉器系列化复制** | 播转粉率 ≥0.4% 的选题（转粉器）优先拆集数 + 合集 + 集间互相导流；发布节奏加密（追更心理是知识类账号第一涨粉杠杆） | 系列合计涨粉 |
| C4 | **置顶评论引导** | 发布后自置顶一条带观点/争议的评论，制造讨论锚点（评论率是互动漏斗里最弱项时的第一杠杆） | 评论率 |

## D 分发

| ID | 技巧 | 具体做法 | 验证指标 |
|----|------|---------|---------|
| D1 | **发布时间窗** | 按账号自身小时级播放序列（overview/all raw_play_daily + 单视频 metrics_trend）选峰前 1h 发布；当前数据不足时用 12:00/20:00 双窗试验 | 冷启动前 2 小时播放占比 |
| D2 | **标题形态 A/B** | 同结构内容轮换「数字型/疑问型」标题与封面版式，按封面点击率（cover_ctr）归因，30 天后固定胜者 | cover_ctr |

## 使用方式

- 人工：写脚本前读 `reports/directives.md`（按当前账号数据装配好的优先级清单）
- 自动：`make analytics-report` 末尾跑 `va.coach` 刷新 directives；video-generation 的口播/分镜自查表引用 directive ID
