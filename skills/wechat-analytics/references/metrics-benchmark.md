# 指标基准与归因树（wechat-analytics）

> 考核机制结论来自 `openspec/changes/wechat-traffic-research`（2026-08-28 调研，含证据等级）；
> 本文档定义分析层用的基准线、指标口径与归因决策树。自有基线积累后（≥3 篇起，≥5 篇出反哺）
> 用自身分位数校准下面的判定值。

## 一、基准线（行业口径，第一基准）

| 指标 | 基准 | 来源口径 |
|------|------|---------|
| 完读率 | <30% 推荐终止；≥50% 进中级池；>65% 持续加推 | 运营圈共识 + 后台「阅读完成率」原生字段 |
| 消息打开率 | 大盘均值 ~1.9%，4%+ 优秀 | 36氪 7242 号样本 + 壹伴 2025Q1 |
| 分享率 | 正常区间 1%-3% | 既有定规（2026-08-26） |
| 完读率第一、粉丝数倒数 | 算法考核排序：完读 > 互动（在看/分享/关注）> 打开 > 停留时长 | 四指标框架 |

**双轨制**：行业基准为主；自有历史 P25/P50/P75 为辅（样本 <3 篇时报告强制声明
「基线积累期」，不给自身分位数评级）。

**自有基线首批实证（2026-08-29，12 篇快照 / 明细 n=3）**：推荐占阅读 83%-95%（63 天）；
有明细的 3 篇完读 28.7%/19.9%/15.6% 全 <30% 终止线，字数与完读强负相关
（5266→28.7%、7181→19.9%、11727→15.6%）；平均阅读时长 55-87 秒；分享率 9.7%-14.5%、
收藏率 2.8%-8.3%（远超行业基准——传播性强，卡点在完读）；关注转化 87 人中 92% 来自
唯一一篇爆文（清单型，5309 阅读）。已据此收紧 blog-writing 写作规范（>4000 默认压缩
变体、90 秒规则、关注带持续价值理由），详见 `blog-writing/references/wechat-retention.md`
「自有基线实证」。

## 二、指标口径（standardize 产出）

| 指标 | 计算 | 说明 |
|------|------|------|
| `open_rate_total` | 阅读 / 送达 | 含推荐流量，可 >100%，传统口径仅作参考 |
| `session_open_rate`（消息打开率） | 公众号消息场景阅读 / 送达 | **对标 1.9%/4% 的可比口径**；人日近似，>100% 看趋势 |
| `read_done_rate` | 后台原生 finished_read_pv_ratio | 完读率，第一考核指标 |
| `share_rate` / `fav_rate` / `zaikan_rate` | 分享/收藏/在看 ÷ 阅读 | 收藏 = 干货质量信号 |
| `follow_conv` / `follow_rate` | 阅读后关注人数（÷ 阅读） | 关注转化主指标 |
| `source_mix` | 逐日×场景 read_user 累加（人日近似） | scene 标签见 SCENE_LABELS；推荐 85.6%（2026-08-29 校准） |
| `retention_curve` | tmpl=28 5% 节点 20 点序列 | delay:true 期间缺失，日频重采 |
| `avg_read_sec` | 平均阅读时长秒数 | 详情页原生 |

口径坑（详见 SKILL.md「已知口径与坑」）：`read_uv_ratio` 是阅读人数占比不是打开率；
消息打开率/来源构成为人日近似；detailpage 仅发表后 30 天内。

## 三、归因决策树（分开归因，wechat-retention 框架数据化）

```
读完率 <30%？ ──是──→ 读完层：修首屏与节奏（前 150 字问题+钩子、标题间隔 ≤1200 字、代码 ≤15 行）
   │否                        └─ 留存曲线可用时：最大跌落节点 × 正文字数 ≈ 流失小节，优先修该节
   否
消息打开 <1.9%？ ──是──→ 打开层：wechat_title 钩子前移 13 字 + 1 个可搜关键词；
   │                      wechat_digest 前 40 字改「痛点/结论+数字」（不动正文）
   否
关注/收藏低于自身中位？ ──是──→ 转化层：补可收藏资产（速查/对比表/决策树）+
   │                            文末往期关联 2-3 篇 + 转化段价值锚定表达
   否
各层达标 → 无动作项（数据缺失的层标注「本次缺失」，不猜测）
```

## 四、因子分桶（桶内有指标样本 <3 只列数据禁结论）

- **长度决策三档**：源稿字数代理（≤2500 / 2500-4000 / >4000）× 完读率 —— 校验
  「>4000 拆系列」定规是否成立
- **标题可搜词**：标题含英文技术专名（claude/codex/deepseek/mcp…）× 消息打开率
- **发布窗口**：群发小时（20:00-21:00 档 vs 早档）× 打开/完读
- **文章类型**：教程/深度/踩坑/观点 × 完读/收藏（类型取自 front matter categories，后续接入）
