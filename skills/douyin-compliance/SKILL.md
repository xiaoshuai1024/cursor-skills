# Douyin Compliance — 平台违规词检查

把要发布的内容（视频口播、标题、封面文字、简介、图文文案）过一遍抖音平台的违规词与敏感词检查，输出命中报告，全部处理完才允许发布。

## 何时用

- 视频发布前（和 video-generation skill 的发布管线配合：渲染前检查口播与 metadata，发布前再复扫一遍）
- 写口播文案 / 标题 / 封面关键词 / 简介之后，发布之前
- 用户说「检查一下违规词 / 敏感词 / 会不会限流 / 平台合规」时

> 与 de-ai-smell 的分工：de-ai-smell 管「文案像不像 AI 写的」，本 skill 管「平台会不会限流」。两个都要跑，互相不替代。

## 检查维度（8 类）

| 维度 | 覆盖 | 级别 |
|------|------|------|
| ① 绝对化/极限词 | 最/第一/唯一/顶级/极致/天花板/封神/yyds 等（《广告法》第九条） | HIGH（商业语境必改） |
| ② 夸大宣传/虚假承诺 | 100%有效/零风险/特效/彻底解决/根治 等 | HIGH |
| ③ 诱导引流/诱导消费 | 微信/QQ/私信/加V/二维码/评论区扣XX/关注我/限时/秒杀/手慢无/闭眼入 等 | HIGH |
| ④ 权威冒用 | 央视推荐/官方指定/专家认证/国家级/特供 等 | HIGH |
| ⑤ 金融收益承诺 | 躺赚/稳赚/保本/日入过千/月入过万 等 | HIGH（一级违规直接封号） |
| ⑥ 迷信/敏感 | 招财/辟邪/转运/消灾/镇宅 等 | HIGH |
| ⑦ 平台行为红线 | 诱导关注/诱导评论/站外导流/虚假人设/AI 生成未声明 | 规则提醒（非词库命中） |
| ⑧ 语境敏感词 | 「教父/大师/天花板/最+形容词」等技术语境比喻 | MEDIUM（人工判断） |

级别定义：

- **HIGH**：命中必须改。平台审核命中即限流/下架，广告法极限词是带货违规的最大来源。
- **MEDIUM**：命中提示人工判断。技术科普语境里「天花板/最值得/教父」通常是比喻，不涉及商业宣传；但平台 AI 审核不认语境，**保险起见能换就换**。
- **INFO**：平台规则提醒，不是词。发布前逐条确认。

## 词库

完整词库与合规替换建议在 `references/word-list.md`（与脚本内嵌词表保持同步，改词库两处一起改）。

词库要点（2026 状态）：

- 平台已升级为「AI 实时语义识别 + 人工抽检 + 用户举报」三重机制，**谐音、拼音、符号拆分变体也会被识别**（"z最"、"医＊用"），不要用错别字规避。
- 2026 新增封控词：yyds、绝绝子、绝版、封神（营销语境使用均触发）。
- 引流硬词：口播/画面出现 QQ、微信、手机号、二维码都会被检测处罚。
- 主题黑名单：同一主体累计 3 次中度违规，旗下所有账号同步限流。

## 工作流

```bash
# 1. 扫描（口播脚本、metadata.txt、封面文案、文章）
make check-douyin path=.video-generation/narrations/xxx.json
# 或直接跑脚本
python scripts/check_douyin_compliance.py --path <file...> --dir <dir>
```

1. **扫**：对每个目标文件输出命中报告（词 | 类别 | 级别 | 位置 | 建议替换）。
2. **改 HIGH**：全部替换，不留。
3. **过 MEDIUM**：逐条人工判断——技术比喻语境但审核不认的，能换就换；替换建议见 word-list.md。
4. **复扫**：HIGH 归零才算过。
5. **发布 checklist（INFO）**：
   - [ ] AI 生成内容声明：抖音发布时勾选 AI 生成声明（视频号/快手各有对应选项）
   - [ ] 封面文字也扫过一遍（封面 OCR 会被识别）
   - [ ] 结尾 CTA 中性化：不用「关注我/评论区扣XX」，用中性价值钩子（「看懂 agent 工程，从拆零件开始」）
   - [ ] 标题 ≤ 平台字数限制且无极限词堆砌
   - [ ] 口播与画面不出现联系方式（QQ/微信/手机号/二维码）
   - [ ] 平台规则以官方规则中心为准，词库只是快检

## 脚本

`scripts/check_douyin_compliance.py`（Python 3 stdlib，零依赖）：

```bash
python scripts/check_douyin_compliance.py --path content/posts/xxx.md          # 单文件
python scripts/check_douyin_compliance.py --path a.json --path b.txt           # 多文件
python scripts/check_douyin_compliance.py --dir .video-generation/narrations   # 目录（.md/.txt/.json/.py）
```

- 输出 markdown 报告，按级别分组；`--json` 可输出机读结果。
- 返回码：HIGH 命中 1，否则 0（配合 Makefile 门禁）。
- 只定位不自动改——词在不在语境里要人判断，自动替换会改坏内容。

## 边界（必须知道）

- 词库来自广告法公开条款 + 第三方运营整理（2026 年时效），**平台规则持续更新，最终以抖音规则中心 / 电商学习中心官方公告为准**。
- 本 skill 面向**技术科普/知识类**内容。医疗、金融、带货、教育资质类内容有额外监管，超出本 skill 范围，需单独资质审查。
- 误报处理：专有名词（如「天花板」「第一」「教父」作为书名/人名/社区昵称）属 MEDIUM，人工判断保留；判断口诀：**这个词去掉，内容受影响吗？** 影响就留，不影响就换。
