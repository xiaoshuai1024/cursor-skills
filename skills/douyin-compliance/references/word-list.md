# 抖音违规词词库（与 scripts/check_douyin_compliance.py 内嵌词表同步）

> 分类：① 绝对化/极限词 ② 夸大宣传 ③ 诱导引流 ④ 权威冒用 ⑤ 金融承诺 ⑥ 迷信敏感 ⑦ 平台行为（非词）⑧ 语境敏感词（MEDIUM）。
> 级别：HIGH = 命中必改；MEDIUM = 人工判断（技术语境比喻通常可留，但平台 AI 审核不认语境，能换就换）。
> 来源：广告法第九条 + 第三方运营整理（2026 时效），最终以抖音规则中心为准。

## ① 绝对化/极限词（HIGH）

| 词 | 说明 | 建议替换 |
|----|------|---------|
| 最、最佳、最好、最具、最赚、最优 | 「最」字类，最高危 | 技术语境改「更/比较级」；商业语境删 |
| 全网最低、最高档、最先进、最受欢迎 | 「最」字组合 | 价格实惠 / 高标准 |
| 第一、中国第一、全网第一、销量第一、行业第一 | 「第一」类 | 备受青睐 / 口碑之作 |
| 唯一、独一无二、仅此一家、没有之一 | 「唯一」类 | 少见 / 少见组合 |
| 国家级、世界级、全球级、宇宙级 | 「级」类 | 高标准 |
| 顶级、极品、极致、顶尖、尖端、终极 | 「级/极/顶」类 | 高水平 |
| 首个、首选、首款、全球首发、全国首家、独家、首家 | 「首/国」类 | 先行尝试 |
| 王牌、销冠、性价比之王、绝无仅有、史无前例、巅峰、至尊、万能、永久、无敌、绝对 | 其他绝对化 | 具体数据代替 |
| 天花板、封神、yyds、绝绝子、绝版 | 2026 新增封控词（营销语境触发） | 技术比喻（能力上限）可 MEDIUM；营销语境必改 |

## ② 夸大宣传/虚假承诺（HIGH）

100%有效、零风险、无副作用、特效、速效、一次见效、1天见效、7天见效、彻底解决、根治、治愈、消炎、杀菌、排毒、增强免疫力、防癌、抗癌、减肥、瘦身、溶脂、祛疤、生发、壮阳、祛湿、改善睡眠

> 医疗功效词普通内容禁用；技术语境「彻底解决」改「系统解决」。

躺赚、稳赚、保本、高收益、日入过千、月入过万、年入百万、稳赚不赔、保本保息、零风险赚钱、一本万利、炒币、数字货币（二级限流）

## ⑥ 迷信/敏感（HIGH）

招财进宝、旺财、旺宅、辟邪、转运、逢凶化吉、化解小人、增强第六感、镇宅、消灾

## ⑦ 平台行为红线（INFO 规则，非词库）

- 诱导关注/诱导评论：结尾 CTA 用中性价值钩子，不用「关注我/评论区扣XX」
- 站外导流：任何形式的 QQ/微信/手机号/二维码
- 虚假人设：冒充精英/专家引流卖课
- AI 生成声明：AI 生成内容（占比超 50%）需在片头/封面/简介标注，发布时勾选 AI 生成声明
- 主题黑名单：同一主体累计 3 次中度违规 → 全账号限流

## ⑧ 语境敏感词（MEDIUM，人工判断）

| 词 | 风险 | 判断 |
|----|------|------|
| 天花板 | 2026 封控词 | 技术语境「能力上限」比喻可留；商业语境必改 |
| 封神、yyds、绝绝子 | 2026 封控词 | 同上 |
| 最+形容词（最值得、最直接、最优先） | 「最」字类 | 技术语境是最高级比较，非广告宣传，可留；保险起见改「更/优先」 |
| 第一 | 「第一」类 | 作为「第一个/第一时间」用法无宣传意图，可留 |
| 教父、大师、专家 | 权威冒用边缘 | 社区昵称（如 TypeScript 教父）非自我宣称，可留 |
| 永久 | 绝对化 | 技术语境「永久链接/永久删除」是术语，可留 |
| 免费 | 中性 | 无风险，仅当配合「领取/限时」时升 HIGH |
| 无敌、万能 | 绝对化 | 技术调侃语境可留，商业语境必改 |

## 合规替换速查

| 原文 | 替换 |
|------|------|
| 全网最低价 | 价格实惠、比日常标价直降 XX 元 |
| 销量第一 | 反馈良好、受欢迎款 |
| 最先进 | 高标准、高品质 |
| 天花板 | 能力上限、标杆 |
| 关注我 | 中性价值钩子（「看懂 X，从 Y 开始」） |
| 评论区扣 1 | 删除，不诱导互动 |
| 稳赚不赔 | 理性评估，市场有风险 |
