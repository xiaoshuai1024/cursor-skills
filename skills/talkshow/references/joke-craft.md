# 写梗管线（talkshow skill / joke-craft，2026-08-28 建库，2026-08-29 定规）

> 分工：`meme-armory.md` 管「用什么梗」（热梗鲜度、句式格式、成品包袱、对标拆解）；本文件管「怎么把梗写好笑」（生成→竞争→修梗的全过程）。
> 来源：7 个开源喜剧 skill 调研提炼（write-chinese-standup / hermes-comedy-writing / comedy-short-video-skill / joke-engineering / comedy-writers-room / stephen-chow-skill / punderstruck），见 `openspec/changes/talkshow-joke-craft/design.md`。
> 转正依据：EP08《我的数字员工一天花多少钱》炸场档成片按本管线生产（笑点位 2.8/卡），用户验收通过。
> 铁律：本管线只回答「梗怎么写」；「梗放哪、放多密、什么不能碰」仍由 SKILL.md 硬边界管，两边冲突时以硬边界为准。

## 1. 态度先行（写任何梗之前）

每个投放位先定**四态度**之一，且必须挂在一个真实事实上：

| 态度 | 内心戏 | 技术版示例 |
|---|---|---|
| 奇怪 | 「这事怎么这么怪？」 | 测试环境越健康，沙箱报警喊得越欢 |
| 可怕 | 「这事有点吓人」 | 这个报警器响了八百次，一次真火都没有 |
| 困难 | 「这事也太难了」 | 文档三页，能跑的两行不在这三页里 |
| 愚蠢 | 「这事也太蠢了」 | 它把退出码 1 当成基础设施塌方 |

- 态度来源于素材里的真实情绪（当时哪里来火/哪里心虚/哪里想笑），**禁止先写梗再倒贴态度**。
- 主体最好是自己（自嘲最安全），客体是事件/行为/现象，不是人。
- 说不清「态度 + 挂的事实」的位置，不加梗。

## 2. 机制选型（一个段子一个主引擎）

**选择启发式**：结果变了→**反转**；程度推到不可能→**夸张**；意义/身份岔开→**误导**；形式/地位/情绪/媒介碰撞→**对比**。

**机制四问**（写包袱前必须能答）：① 观众预期是什么？② 铺垫证据在哪？③ 违背点在哪？④ 新结果为什么仍然连贯（= 挂的真实机制）？

### 机制库（四族，选适配技术号的细目）

**反转族**
- 打脸：立 flag → 结果打脸（「包能跑的」→ 没跑）
- 经典反转：唤起熟悉套路 → 换结局
- 假装正经：体面表面 → 掩着慌/私心（「发布很顺利——顺利回滚了」）
- 段子剧：铺垫是故事 A → 共享连接点揭出故事 B 且自洽（F10 司法宇宙属此族）

**夸张族**
- 攀比升级：同一维度逐轮加码，每轮必须有新增信息
- 行为沙雕：荒诞动作放大，但动机不能缺（荒诞≠没道理）
- What if 推演：规则荒诞 → 推到极端（F6 博尔特式；推演对象必须是中性/正面形象）

**误导族**
- 理解错位：同一句话，双方各执一个都成立的解读（「发生了错误」——废话文学 A7 属此）
- 一语双关：一个词撑两层意思（乐子哥式「一码归一码」；自指式用，不裸用）
- 人物错位：给机制/进程起外号、当角色演（E 区拟人宇宙，背锅侠/惯犯/物业）

**对比族**
- YY 想象坍塌：理想版 vs 现实版（A6 对比联句、F5 理想缩水三连）
- 正话反说：一本正经夸烂设计（郎才式反讽，「顶级设计，一个子串走天下」）——必须挂真实缺陷
- 疼不在己：铺垫把惨安在 A 头上，抖出来是 B
- 瞬间变脸：明确触发点后情绪秒切（冷面补刀的引擎）
- 年代/风格包装：内容不变，换一种时代的/文体的壳（E1 对仗副标「空搜一把惊四座」）

**纪律**：一稿**一主机制**，副机制至多一个且必须强化同一观众预期；三族同屏承重 = 机制漂移，砍到一主一副或拆段。

## 3. 写包袱（包袱先行 × 第三联想）

1. **先写包袱，再倒推铺垫**：包袱句先定，铺垫句 backward 写。铺垫的任务是建立「第一故事」的目标假设，包袱揭示「第二故事」的重新解读——两个故事在包袱词上交汇且都成立。
2. **第三联想规则**：把这个位置的前两版联想**直接扔掉**（第一二联想必然是被用烂的高频梗），第三版起才允许成稿。F 区成品包袱只作垫场，承重包袱必须过本条。
3. **包袱词纪律**：包袱词不进铺垫句（含近义变体）；包袱词放包袱句**句尾**；铺垫不解释反转方向。铺垫越正经，包袱越响。
4. **压缩**：删掉观众能自行推断的信息；铺垫比包袱长很多时先砍铺垫。「在完全说透之前半句收住」——解释掉隐性连接 = 杀死 aha。

## 4. 段落六功能与 Tag

段子段落按功能组装（不是句式模板，是功能清单）：

1. **定位**：最少信息交代人物/关系/场景。
2. **正常预期**：让观众知道正常人会怎么理解或行动。
3. **异常证据**：改变预期的具体事实（真实可溯源）。
4. **笑点**：句尾完成反转/升级/具象化。
5. **Tag**：包袱抖完**不换前提、不重新解释**，从同一发现再挖 1-3 刀，每刀必须有新增画面或新增风险。
6. **推进**：引入后果/新场景/新情绪风险，不许原地换词。

- **Tag 与 callback 分工**：Tag 是段内连抖（不占热梗词配额）；callback 是结尾回收（全片 ≤1 次，放揭底/金句位）。互不顶替。
- 无新增信息的 Tag 删掉——「句句有戏」靠语气词/拟人/冷面撑（见 SKILL.md 密度底线），不靠硬凑 Tag。
- 报错清单/历史包袱/盘点类内容天然适配 Tag（三翻四抖就是清单 + Tag 的近亲）。

## 5. 诊断修梗（不好笑时的唯一合法入口）

### 第一步：判 H 状态（joke-engineering）

| 状态 | 症状 | 手术 |
|---|---|---|
| H1 太明显 | 观众提前猜到包袱 | 换框架拉大连接距离（换机制重写） |
| H2 太隐晦 | 观众接不住 | 加脚手架（上下文线索），**不许解释梗** |
| H3 低密度 | 单连接点，单薄 | 给元素加第二职能（同元素在两个框架里都干活） |
| H4 解释过度 | 包袱被说破 | 在说透前半句收住，把连接留给观众 |
| H5 声音违和 | 不像本号说话 | 换成本号会用的说法（权威自信 + 自嘲位） |
| H6 铺垫臃肿 | 动量死在包袱前 | 删解释性元素，提高信息-词比 |

### 第二步：六维审稿打分（0-3 分，先修最低维）

| 维度 | 0 分 | 3 分 |
|---|---|---|
| 真实 | 泛泛而谈 | 细节暴露机制与代价，可溯源 |
| 清晰 | 需要回读 | 极少信息即建立预期 |
| 惊奇 | 可预测 | 转向意外且回看合理 |
| 声音 | 通用文案腔 | 只能本号说出的口吻 |
| 可演 | 依赖文字解释 | 身体/停顿/角色切换能成立（文章链路 = 朗读流畅） |
| 密度 | 长段无回报 | 笑点持续且不牺牲讲解 |

- **修梗按 punch-up 次序执行，先修最低维**：修清楚 → 修立场（态度）→ 修具体（真话/原话/数字/物件）→ 修惊奇（藏哪条信息/换哪个词）→ 修节奏（砍铺垫、包袱词句尾）→ 修表演（只有演/读才成立的瞬间）→ 修连接（孤立笑点转成后果/升级/Tag）。
- 禁止凭感觉堆比喻——那是把第 4 步「修具体/修惊奇」的活全推给类比，类比密度超限（一段 ≤1、一篇 ≤3）还撞 de-ai-smell。

### 第三步：模拟观众三问（自查假设，不是证据）

- **毒舌观众**：这梗是不是听过类似的？（高频梗漏网 → 回第三联想）
- **较真观众**：逻辑有没有洞？字面理解会不会更成立？（技术梗尤其防「其实机制不是这样」）
- **捧场观众**：笑点具体在哪一句哪个词？我真的会笑吗？（说不出具体笑点 = 没有笑点）
- 三问结论只作假设；「好笑」的最终证据 = 发布后真实数据与用户验收。

## 6. 双链路落法差异

| | 视频口播稿 | 文章 |
|---|---|---|
| 投放单位 | 卡（投放区：前 30s 钩子/过桥句/揭底句，密度三档） | 段（投放区：开头 800 字钩子/小节过桥句/结论揭底句，**默认标准档**） |
| 投放步动作 | 标投放区 + 档位 | 标投放位 + **禁区清单**（数据段/结论/CTA 一次性标出，禁区外默认不放，比视频更保守） |
| 分句/段落纪律 | 8-14 字/分句（乐子哥画像） | 段 ≤4 行、段间空行（blog-writing 现规） |
| Tag 落法 | 卡内连续分句/连续镜头 | 同段连续两句或紧邻段 |
| 交付门禁 | 三道门 + TTS 节拍步（punch/揭底句 `--emo dyn`、钩子句 scale 1.0 收着） | 三道门 + de-ai-smell 中文句法层（的链/虚动词/类比密度） |
| 结构关系 | deck/三要素/钩子回收表照常 | blog-writing 骨架/类型/配图照旧，段子只进修辞层 |

## 7. 常见失败（自查清单）

- 用金句、升华、人生道理代替事件（「态度先行」没做）。
- 只贴标签不给证据（「离谱/绝了/破防」后面没有画面）。
- 每个笑点都是「像谈恋爱/像上班/像前任」式通用类比。
- 为了「像脱口秀」连续反问、喊口号、解释笑点。
- 三族机制同屏承重（机制漂移），或连续多个完整包袱无 Tag 无小刺激（观众会累，审核会警觉）。
- 荒诞升级变随机堆怪（escalation 每级必须有新增信息，否则是 noise 不是 funny）。
