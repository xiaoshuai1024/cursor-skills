# 热梗弹药库（talkshow skill / 2026-08-28 联网搜集建库）

> 用法：A 区是**句式格式库**（格式不过期，优先用）；B 区是**现役热梗词**（有保质期，用前核对注记）；C 区是**技法**；D 区是**红线与过期梗**（禁/慎）。
> 每个格式给：结构模板 → 技术示例（供仿写）→ 适用位置。示例仅示范，写稿时必须换成当前内容里的真实机制。

## A. 句式格式库（主打，不过期）

### A1. 定义反转（「什么叫XX？那是XX」）★ 用户点名格式
- **模板**：`什么叫XX？那是YY。` —— YY 对 XX 做降维拆穿，正经词配大实话。
- **技术示例**：
  - 「什么叫退出码？那是程序的遗言。」
  - 「什么叫沙箱报警？那是环境越正常，它喊得越欢。」
  - 「什么叫技术债？那是你跟三个月后的自己借的高利贷。」
  - 「什么叫灰度发布？那是先拿百分之一的用户探雷。」
- **适用位置**：钩子区（前 30s 立人味）、揭底句、术语首次出现处（天然承担讲解职责，梗和知识一体）。
- **要点**：YY 必须同时是真的（技术上站得住）+ 意外的（换个人话视角）。只是俏皮但人人皆知的不用。

### A2. 性价比反转（「不是XX买不起，而是YY更有性价比」）
- **模板**：`不是XX（贵/难/正规路线），而是YY（便宜/野路子）更有性价比。`
- **技术示例**：「不是文档读不懂，而是源码更有性价比——文档说它优雅，源码说它凑合。」
- **适用位置**：选型对比段、揭底句。

### A3. 尽头体（「XX的尽头是YY」）
- **模板**：`XX 的尽头，是 YY。`
- **技术示例**：「Debug 的尽头是重启，重启的尽头是玄学。」「所有抽象的尽头，是一行没写注释的 SQL。」
- **适用位置**：金句收束（一个片子最多一次）。

### A4. 刺客体（「XX刺客」）
- **模板**：把「隐性代价」命名成刺客。
- **技术示例**：「依赖注入，构建产物里的体积刺客。」「这句 console.log，性能刺客。」
- **适用位置**：过桥句、报错/踩坑盘点。

### A5. 永动机体（「XX永动机」）
- **模板**：`XX 永动机——它不产出能量，只产出 YY。`
- **技术示例**：「重构永动机：不产出功能，只产出 diff。」
- **适用位置**：过桥句吐槽。

### A6. 对比联句（「从从容容、游刃有余 vs 匆匆忙忙、连滚带爬」）
- **模板**：前后两种状态各配一组四字叠词，反差即笑点。
- **技术示例**：「文档里的部署：从从容容，游刃有余。我手里的部署：匆匆忙忙，连滚带爬。」
- **适用位置**：教程类「理想 vs 现实」对比、揭底句。出处：2025-2026 流行对仗梗。

### A7. 废话文学（「听君一席话，如听一席话」）
- **模板**：引用一段「正确但零信息」的原话，原样复述收尾。
- **技术示例**：「报错信息写着：发生了错误。听君一席话，如听一席话。」
- **适用位置**：吐槽报错/文档信息量。**注意**：引用的原文必须真实存在（截图/quote 镜头配合）。

### A8. 震撼体（「我不理解，但我大受震撼」）
- **模板**：展示离谱真实代码/设计后，固定此句收。
- **技术示例**：「它把退出码 1 当成了基础设施塌方。我不理解，但我大受震撼。」
- **适用位置**：揭底句。必须紧跟真实离谱事实。

### A9. 认命体（「那咋了」「如何呢？又能怎呢」）
- **模板**：陈述一个无法解决的既定事实，用认命语气收。
- **技术示例**：「这个 bug 官方标记为 by design。那咋了。能跑就行。」
- **适用位置**：踩坑段收尾。语气要豁达，不能丧（负面情绪段禁用）。

### A10. 打工人共鸣（「班味」「那叫上班」式自嘲）
- **模板**：把技术行为对齐到打工人共同经验。
- **技术示例**：「我一天搜八次空八次，那叫上班。」「这段代码班味很重——一看就是被 deadline 逼出来的。」
- **适用位置**：过桥句。自嘲类，最安全。

## B3. 动物纪录片旁白宇宙（2026-08-29 实抓对标：抖音「万物探索之旅」）

> 对标实抓（douyin-topic search_works.py，2026-08-29）：「刚出生的小驯鹿，却被母亲残忍地抛弃」（14.6 万赞）/「河狸：这很合理」（1.3 万）/「红松鼠：自从疯了以后，整个鼠都神经了不少」。可迁移格式三条：

1. **纪录片旁白腔**：用《动物世界》解说腔讲技术事件——「在代码的草原上，每个 agent 都要找到自己的生态位。雨季来了，也就是版本发布周。」旁白越正经，角色越离谱，反差越大。
2. **角色第一人称冷面短评**：「XX：这很合理。」——给工具/报错一句第一人称收尾，冷面不解释。系列化复用（每个工具一句性格签名）。
3. **情绪直给事件标题**：「刚出生的 X，却被 Y 残忍地 Z」——把技术事故说成动物世界剧情（「刚上线的功能，却被用户残忍地点开」）。用于小节标题/分镜，正文不过密使用。

## C. 技法（写梗的手法，格式之上）

1. **预期违背**（段子的核心逻辑）：铺垫建立预期 → 包袱打破预期。铺垫越正经越好笑，技术讲解天然正经，直接用。
   - 公式：`段子 = 正经铺垫 + 反转包袱`；铺垫里**不能剧透**反转方向。
2. **三翻四抖**（相声节奏）：同方向铺垫三次，第四次反向抖。清单类（报错列表、通缉名单、历史包袱）天然适配——前三条正常列，第四条荒诞化。
3. **callback（扣题回扣）**：把前面埋过的梗在结尾意想不到处回收，用新包袱接旧包袱。全片 ≤1 次，放揭底句或金句位；CTA 段禁用。
4. **谐音梗警告**：谐音梗成本最低也最廉价，且「谐音梗扣钱」本身就是梗——要自指式用（「谐音梗要扣钱，这个我认」），不裸用。
5. **良性违背**：笑点不能违背「观众对讲解者的信任预期」——数据、结论、安全边界处永不违背，只在叙事和比喻层违背。

## D. 红线与过期梗（禁/慎）

- **禁（撞发布门禁）**：「遥遥领先」（极限词风险）、「吊打/碾压/秒杀」（贬低竞品+极限词）、「扣 666/评论区扣X」（抖音硬红线）、「不转不是XX」（道德绑架）、攻击性/祖安类梗、谐音点名真实公司黑料。
- **慎（圈层成本高，技术号受众未必接）**：饭圈梗、二次元黑话（除非内容本身相关）。
- **已过期（2026-08 时点，用了显旧）**：绝绝子、栓Q、yyds 口播直读（字幕可用）、爷青回（低频可用）、awsl。
- **TTS 注记**：缩写类（yyds/u1s1）克隆声会逐字母读，口播稿禁用；梗词进口播稿前过一遍 `normalize_for_tts` 白名单思路——读音没把握的词先跑探针。

**抓到的真实标题样本**：「德意忘形：扩军五十万，提剑指东线」「恶贯满英：资本异化初代霸主，无恶不作带不列颠」「英之恶来：莽尽帝国生死来，留得斜阳照断壁」「东方的树叶：被大汉丝绸贸易倾销，罗马自此礼崩乐坏」「我即钢铁：请大声告诉我，保尔柯察金是什么？」

**可迁移格式**：
1. **四字谐音改字标题**（得意忘形→德意忘形、恶贯满盈→恶贯满英）——把主题词嵌进成语。技术版：「一码归一码」（退出码案主题双关）、「码不停蹄」「Bug 意忘形」「缓存绝伦」（从容绝伦）。用于标题/封面 hero/结案句，口播里当 callback 用（「结案，一码归一码」）。
2. **主标（梗）+ 破折号 + 对仗长句副标**——副标用仿古对仗把事情说大（「莽尽帝国生死以」）。技术版：「空搜一把惊四座，冤深全是退出码」。用于封面/标题，口播不用（文言腔克隆声读着怪）。
3. **把抽象系统当角色演**（国家→角色，有性格有动机）——技术版：进程/组件/命令当角色（背锅侠、惯犯、物业）。本片已在用（false 被铐走、125 共用门牌）。
4. **系列化栏目名**（《五月花》《知更鸟》系列 + 「重读我的宝藏课」标签）——技术版：系列名固定 + 「卷宗 0004」式档案编号贯穿。
5. **他翻过的车（别学）**：观点夹带私货、类比过度引战——对应我们的红线：梗挂事实，观点留证据，不点名开炮。

### E2. 郎才（游戏解说整活，63.6万粉，单条 5.4万-32.3万赞）
**抓到的真实标题样本**：「顶级头脑李白给我看麻了」（32.3万）、「这牛魔真能活」（29.8万）、「策子这个人当真表里不一两面三刀啊」（29.5万）、「哥们你真气着我了」（11.4万）、「对抗路鲁班背后的真相」

**可迁移格式**：
1. **情绪直给短句标题**——不描述内容，直接给反应（看麻了/真能活/气着我了）。技术版：「这报错真能活」「看得我直接麻了」「这签名真敢定啊」。完播向：反应前置比内容前置更钩人。
2. **给对象起外号**（司马懿→策子、暗信）——技术版：给机制起外号（宽签名→「一口清」？runner→「背锅侠」）。外号一旦立住，全系列复用成记忆点。
3. **反讽式夸赞**（「顶级头脑」）——技术版：「顶级设计，一个子串走天下」「这才叫架构，报错全靠猜」。反讽必须挂在真实缺陷上。
4. **第一人称对手戏**（「哥们你真气着我了」——把对手当熟人吐槽）——技术版：跟工具/报错对话（「rg 哥们，你没病，是真没搜到」）。

### E3. 两个账号共同的底层公式（对照本号怎么用）
- **情绪浓度 > 信息完整度**（在标题/开头层）——但我们只借「前 30s」这一段：讲解段仍是本号命根的讲透型，这在 humor-style-research 提案里定了界。
- **角色化叙事是最大公约数**：乐子哥演国家、郎才演英雄——技术内容演进程/组件/报错，零成本移植且天然安全（不碰真人不碰公司）。
- **谐音/双关当「案卷编号」用**：不密集抖，一片一次，放在标题或结案，当品牌记忆点。

## F. 高杀伤备选包袱库（2026-08-28 二轮补充，用户点名「要更好笑」）

> 定位：A 区是句式格式（稳），本区是**成品包袱**（炸）——每个都给可直接改写的结构 + 技术化套法。用前过三道门（de-ai / 合规 / 密度）。

### F1. 场景降维（阎王殿式）
- **来源**：经典地狱笑话「我梦到我死了，阎王让我给生死簿做后台管理系统」——荒诞场景里角色仍在干本行。
- **套法**：把技术对象放进完全不相称的场景，它还在干活。「这个 bug 跟到阴间还在复现」「火化炉也有排期表，也是 Crab」。

### F2. 悖论清单（程序员四件套式）
- **来源**：「程序员最讨厌的四件事：写注释、写文档、别人的代码没注释、让别人写注释」——三项铺垫 + 一项自指反转。
- **套法**：列 3 个真讨厌项，第 4 项换成「自己刚才干的事」。清单类内容专用。

### F3. 甩锅圣体（It works on my machine 式）
- **来源**：「在我机器上是好的！」——全球程序员通用免责声明。
- **套法**：环境/沙箱/配置类内容必配。「报错说你环境有问题，翻译：它自己有问题。」「在我内核上是好的。」

### F4. 不是故障是特性（Feature 式）
- **来源**：「这不是 bug，这是 feature」——把缺陷说成设计。
- **技术套法**：「报警器误报不是故障，那是它 KPI 高——按次计费，冤案越多绩效越好。」

### F5. 理想缩水三连
- **来源**：「20 岁我要改变世界，30 岁我要改变公司，40 岁我要改变团队」——递进坍缩。
- **套法**：「文档写的：开箱即用。教程说的：小步配置。我跑的：逐行排雷。」

### F6. 荒诞推演（博尔特式）
- **结构**：规则本身荒诞 → 把它推演到一个极端真实的人物/场景上。「谁跑得快谁是小偷 → 按这标准，博尔特出门都得自首。」
- **要点**：推演对象必须是公认无争议的正面/中性形象（运动员/自然现象/数学常数），禁拿具体个人/公司开涮。

### F7. 反向定义（false 式）
- **结构**：「X 的本职就是失败。它要是成功了，那才是出事了。」——用职责任义反杀。
- **套法**：「监控要是报平安，那才吓人」「这个报错要是消失了，先别高兴」。

### F8. 系统性失明（监控一切正常式）
- **结构**：「就像监控坏了的打开方式，是给你播一张静态图，上面写着『一切正常』」——用一件荒诞日常事精准映射技术缺陷。
- **要点**：映射物的荒诞点必须和技术缺陷**同构**（掩盖方式一模一样），观众笑完能懂机制。

### F9. 抽奖化（拆盲盒式）
- **结构**：「以后看 125 报警，全靠拆盲盒——你永远不知道开出来是真事故，还是替罪羊。」把不确定性包装成抽奖/开盒。
- **同类**：开盲盒 / 抽卡 / SSR——「这次上线是 SSR 还是 N 卡，全看天意。」

### F10. 司法宇宙贯口（冤案长线）
- **结构**：立案 → 通缉 → 铐走 → 撞号 → 门牌 → 物业 → 当庭释放 → 国家赔偿——一条隐喻宇宙从头贯到尾，每个新包袱都在同一个宇宙里加码。
- **要点**：隐喻宇宙一旦开场就不许跳出（本片 false 被铐走、125 门牌号、当庭释放全在同宇宙）；中途换隐喻宇宙 = 前面白埋。

## G. 联网搜梗引擎（写稿前必做，2026-08-28 用户定规：写口播稿时搜当期热梗融入，梗要密集）

### 鲜度规则

1. 写稿时搜到的梗**当月可用**；上季度梗需判断是否仍在役（搜索结果里近期内容还在玩 = 在役）。
2. 同一片内热梗词 ≤3 个（热梗贵精不贵多，句句有戏靠语气/拟人/冷面撑，不靠堆梗词）。
3. TTS 口播稿只收「读音可 predicting」的梗——缩写类（yyds）、英文梗词先过发音探针再进口播，否则只进字幕/标题。

### 密度对照（炸场档基准 = humor-pilot-exitcode-max）

- max 样片（用户认可基准）：14 卡 27 个笑点位 ≈ **每卡 1.9 个**，其中完整包袱 12 个、语气词/冷面/拟人小刺激 15 个。
- 「梗再密集」的落法 = 提高小刺激密度（语气词、拟人动作、冷面补刀），完整包袱仍 ≤1.5 卡/个——句句有戏 ≠ 句句是包袱。
