# 通用违禁词词库（广告法红线，四平台通用）

> 与 scripts/check_compliance.py 内嵌词表同步。平台差异词见 platform-rules.md。
> 级别：HIGH = 命中必改；MEDIUM = 人工判断（技术语境比喻通常可留，但平台 AI 审核不认语境，能换就换）。

## ① 绝对化/极限词（HIGH，全平台）

| 词 | 建议替换 |
|----|---------|
| 最、最佳、最好、最具、最赚、最优 | 技术语境改「更/比较级」；商业语境删 |
| 全网最低、最高档、最先进、最受欢迎 | 价格实惠 / 高标准 |
| 第一、全网第一、销量第一、行业第一、中国第一 | 备受青睐 / 口碑之作 |
| 唯一、独一无二、仅此一家、没有之一、无可替代 | 少见 / 少见组合 |
| 国家级、世界级、全球级、宇宙级 | 高标准 |
| 顶级、极品、极致、顶尖、尖端、终极 | 高水平 |
| 首个、首款、首选、全球首发、全国首家、独家、首家 | 先行尝试 |
| 王牌、销冠、性价比之王、绝无仅有、史无前例、巅峰、至尊、万能、永久、无敌、绝对 | 具体数据代替 |
| 天花板、封神、yyds、绝绝子、绝版、标杆、断层领先、遥遥领先 | 2026 隐性极限词；技术比喻可 MEDIUM，营销语境必改 |

## ⑨ 语境敏感词（MEDIUM，人工判断）

| 词 | 判断 |
|----|------|
| 天花板、封神、yyds、绝绝子 | 技术语境「能力上限」比喻可留；商业语境必改 |
| 最+形容词（最值得、最直接、最优先） | 技术语境是最高级比较，可留；保险起见改「更/优先」 |
| 第一 | 「第一个/第一时间」用法无宣传意图，可留 |
| 教父、大师、专家 | 社区昵称（如 TypeScript 教父）非自我宣称，可留 |
| 永久 | 技术语境「永久链接/永久删除」是术语，可留 |
| 免费 | 无风险，仅当配合「领取/限时」时升 HIGH |
| 无敌、万能 | 技术调侃可留，商业语境必改 |

## 合规替换速查

| 原文 | 替换 |
|------|------|
| 全网最低价 | 价格实惠、比日常标价直降 XX 元 |
| 销量第一 | 反馈良好、受欢迎款 |
| 最先进 | 高标准、高品质 |
| 天花板 | 能力上限、标杆 |
| 治疗/根治 | 改善 / 缓解 / 系统解决 |
| 关注我 | 中性价值钩子（「看懂 X，从 Y 开始」） |
| 评论区扣 1 | 删除，不诱导互动 |
| 稳赚不赔 | 理性评估，市场有风险 |
