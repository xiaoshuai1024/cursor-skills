# AI 味禁词表（分类 + 替代）

> 本表是 `de-ai-smell` skill 的权威词表。扫描脚本 `scripts/check_ai_smell.py` 的 PATTERNS 与它保持一致。

## 两级口径（先看这个）

词不是一刀切，分两级：

- **L1 绝对禁词（出现即改，无例外）**：兜底 / 铁证 / 说白了 / 先说 / 根子 / 扎眼（2026-08-03 定规）；**PPT 名词（赋能/闭环/抓手/打通/对齐/拉通/洞察/沉淀/底层逻辑/全生命周期/降本增效/技术底座）+ 口头禅（一句话/一件事/踩一遍）+ 值得注意/我的判断是/恰恰**（2026-08-26 定规，业务术语与引用语境也不豁免）；**记账类比（X 的账 / 这笔账 / 算账 / 算总账）**（2026-08-27 定规，字面义账单/账号/账户/分账不在此列）。
- **L2 高危慎用词（命中即提示，人工判，确有实质才留）**：本质 / 澄清 / 撕开 / 真相 / 至关重要 / 护城河 / 分水岭 …。这些词本身有意义，AI 味在于它们常被用来**铺垫升华**或**戏剧化煽情**。

> 判断 L2 的标准一句话：删了句子更干净、更像人说的话——改；真在表实质（如「问题的本质」「澄清一个事实」「事件真相」）——留。**L2 不是「绝对不能用」，是「用之前先问一句：这里在说人话，还是在装腔？」**

## A. 口语套话连接词（用户点名 + 同类，出现即删）

| 禁词 | 替代 |
|------|------|
| 说白了 | 删掉，直接说结论 |
| 先说 / 先说结论 / 先给结论 | 直接甩结论，不加预告 |
| 根子 | 原因 / 根本 / 源头 |
| 扎眼 | 显眼 / 突兀 / 一眼看出 |
| 总之 / 总而言之 | 删掉，直接说 |
| 回过头看 / 现在回头看 | 删掉或换成具体时间点 |
| 说实话 / 老实讲 | 偶尔可用；连续出现删 |
| 毕竟 | 看语境，「毕竟」删了多半更干净 |

## B. 新晋 AI 网络黑话 / PPT 名词〔**2026-08-26 定规：全部 L1 无例外**，业务术语语境不豁免〕

| 禁词 | 替代 |
|------|------|
| 兜底 | 回退 / 降级 / 防线 / 把关 / 拦下来；「兜底页」→「降级页」 |
| 铁证 | 实测 / 日志为证 / 数据摆在面前 |
| 赋能 | 帮 X 做成什么（具体动作） |
| 闭环 | 完整回路 / 完整流程（「SaaS 商业闭环」→「从获客到续费的完整回路」，定规后不豁免） |
| 抓手 | 具体手段 / 方法 |
| 打通 | 连上 / 对接 / 串起来 |
| 对齐 | 统一 / 说清楚（工程语境「字段对齐」这类物理对齐可换「匹配/一致」） |
| 拉通 | 协调 |
| 洞察 | 发现 / 结论 |
| 沉淀 | 攒下来 / 积累 / 留下（「沉淀的东西」→「留下的经验」） |
| 降本增效 | 从 X 天降到 Y 小时 |
| 底层逻辑 | 原理（定规后一律改，不再留「讲原理可留」豁免） |
| 全生命周期 | 从建到删 / 全程 |
| 技术底座 | 基础设施 / 底层 |

## C. 空洞强调词

| 禁词 | 替代 |
|------|------|
| 至关重要 | 具体影响 |
| 不可或缺 | 没有它会怎样 |
| 意义深远 | 具体收益 |
| 真正的（多数） | 删（「真正的需求/瓶颈」这类有实质才留） |
| 恰恰〔**L1 无例外，2026-08-26**〕 | 删（「恰恰相反」「恰恰是」都算） |
| 我的判断是〔**L1 无例外，2026-08-26**〕 | 删前缀（「我的判断很直接」同） |
| 核心在于 | 删或换「关键是」 |
| 终极 | 删 |
| 护城河 | 优势 |
| 分水岭 | 标志 |
| 定时炸弹 | 隐患 |
| 本质 / 本质上 [L2] | 名词「问题的本质」可留；空洞副词「本质上…」删或换「原理」 |
| 澄清 [L2] | 正常动词「澄清事实」可留；铺垫「需要澄清的是 / 澄清一下」删 |
| 真相 [L2] | 普通名词「事件真相」可留；戏剧化「真相是… / 揭开真相」删 |

## D. 套话开场（删掉，直接进入内容）

- 综上所述 / 由此可见 / 不难看出
- 值得注意的是 / 值得一提的是 / 需要指出的是
- 不难发现 / 毋庸置疑 / 众所周知 / 不言而喻 / 诚然
- 在…的今天 / 在…的背景下 / 随着…的发展
- 在当今这个快节奏的时代 / 在这个信息爆炸的时代
- 「先X」口语开场：先泼盆冷水 / 先给大家 / 先聊聊 / 先问一句（删掉直接进内容）
- 自问自答设问句：key 哪来？/ 怎么用？/ 它是什么？（改直接陈述）

## E. 套话收尾（删掉，让内容自然结束）

- 以上就是…的全部内容
- 希望对你有帮助 / 希望本文对您有所帮助
- 你学会了吗
- 随着 AI 不断进化 / 未来可期（为结尾而结尾）

## G. 句式红线（见 SKILL.md 行为规范）

- 「不是 A，而是 B」排比（AI 句型第一名；**2026-08-26 定规：一律改直陈，「A，而不是 B」形态同禁，「对比有实质」不豁免**，纯否定+让步不算）
- **记账类比**〔**2026-08-27 定规：升 L1 无例外**〕——「X 的账」「这笔账」「算账」「算总账」「账要拆开」这类把成本/时间/取舍写成记账的比喻全禁。直说：「时间的账要拆开」→「时间分两块看」；「这笔账划得来」→「值得」；「算总账」→「加起来看」。**字面义不在禁列**：账单（token 账单是真的单）、账号、账户、分账（支付术语）、对账（数据/支付对账）、结算账期/账务。视频签名句「记工程的账」系 2026-08-26 定稿品牌资产，不按本条改（要动签名另定）。
- 三连排比 / 任意凑排比（为对仗而对仗、为排比而排比，砍到最有力的一个）
- 破折号每篇 >2
- 连续 3+ 处冒号
- 每节加粗 >2 处
- 无意义类比 / 比喻（喻体和本体无实质关联，只为装深度；见 de-ai-patterns.md）

## H. 戏剧化 / 煽情用词（L2 慎用）

AI 特别爱把技术叙述写成「揭秘真相」的戏。这类词删掉戏剧外衣，换成具体动作。

| 禁词 | 替代 |
|------|------|
| 撕开（撕开真相 / 撕开面具）[L2] | 换具体动作，删戏剧化外衣 |
| 揭开面纱 / 戳破 / 剥开 [L2] | 同上，直接说做了什么 |

## I. AI 口头禅 / 模糊表达〔**2026-08-26 定规：升 L1 无例外**，引用语境（引 skill 描述原文）也不豁免——新稿引用时改为转述〕

| 词 | 替代 |
|------|------|
| 一句话 | 「一句话说清 / 一句话总结 / 描述一句话点透」→ 直接说内容，或改「核心分工是」「描述点透了 X」 |
| 一件事 / 一件小事 | 换具体所指：一次变更 / 一个目标 / 一个功能 |
| 踩一遍 / 踩坑 | 换「重新走一遍 / 再犯一次 / 从头再来」 |

## J. 翻译腔句法（2026-08-26 新增，源 novel ai-smell-checklist 取舍）

英语句式直译进中文的语法残留。前三项 + 预判冒号已进脚本 ⊙ 机械提示，其余人工判。完整 ✅/❌ 例句见 `de-ai-patterns.md`「中文句法层」。

| 句法 | 替代 | 检测 |
|------|------|------|
| 的链 ≥3（连续「的」定语链） | 拆句 / 冒号列举：「规则驱动、可扩展、轻量」 | 脚本 ⊙ |
| 虚动词：进行/作出/加以 + 动词 | 删虚动词直接用动词：「进行优化」→「优化」 | 脚本 ⊙ |
| 形容词 + 冒号预判：「结论很明确：」「原因很简单：」 | 删预判短语，内容直接成句 | 脚本 ⊙ |
| 滥用「之一」 [L2] | 直接判断或列举（one of the 机械翻译） | 人工 |
| 「是……的」结构滥用 | 「这个决定是他们做出的」→「他们一起决定的」 | 人工 |
| 介词短语堆砌（多介词前置头重脚轻） | 重排：「昨天开会时我们团队提了个方案」 | 人工 |
| 代词高频复指（连续「它/他们」驱动主语） | 省略主语靠语境衔接 | 人工 |
| 物理动词 + 抽象宾语 [L2]：击穿 / 打穿 / 接住 / 穿透 / 收紧 | 「论证被击穿」→「论证不成立」；「反馈都接住」→「都记下了」 | 人工 |
| **守住 / 守好 / 守牢 / 看住 / 护住**〔**2026-08-28 用户定规：禁止轻易使用，按 AI 味句式对待**；「守住底线/折扣守没守住」这类抽象宾语一律改〕 | 「折扣才守得住」→「折扣就跑不掉 / 折扣才稳」；「守没守住」→「还在不在」；「守住优势」→「优势还在」 | 人工 |
| 否定句首（「不是…/没有…/并非…」起句制造顿悟铺垫） | 删铺垫直接说事（行为规范 #4 同族变体） | 人工 |
