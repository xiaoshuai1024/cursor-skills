# AI 味禁词表（分类 + 替代）

> 本表是 `de-ai-smell` skill 的权威词表。扫描脚本 `scripts/check_ai_smell.py` 的 PATTERNS 与它保持一致。

## 两级口径（先看这个）

词不是一刀切，分两级：

- **L1 绝对禁词（出现即改，无例外）**：兜底 / 铁证 / 说白了 / 先说 / 根子 / 扎眼。2026-08-03 定规，技术语境也不留，别在反讽 / 术语之间来回纠结。
- **L2 高危慎用词（命中即提示，人工判，确有实质才留）**：本质 / 澄清 / 撕开 / 底层逻辑 / 真相 / 赋能 / 闭环 / 抓手 / 洞察 / 沉淀 …。这些词本身有意义，AI 味在于它们常被用来**铺垫升华**或**戏剧化煽情**。

> 判断 L2 的标准一句话：删了句子更干净、更像人说的话——改；真在表实质（如「问题的本质」「澄清一个事实」「事件真相」）——留。**L2 不是「绝对不能用」，是「用之前先问一句：这里在说人话，还是在装腔？」**

## A. 口语套话连接词（用户点名 + 同类，出现即删）

| 禁词 | 替代 |
|------|------|
| 说白了 | 删掉，直接说结论 |
| 先说 / 先说结论 / 先给结论 | 直接甩结论，不加预告 |
| 根子 | 原因 / 根本 / 源头 |
| 扎眼 | 显眼 / 突兀 / 一眼看出 |
| 总之 / 总而言之 | 删掉，直接说 |
| 回过头看 / 现在回头看 | 删掉或换成具体时间点 |
| 说实话 / 老实讲 | 偶尔可用；连续出现删 |
| 毕竟 | 看语境，「毕竟」删了多半更干净 |

## B. 新晋 AI 网络黑话

| 禁词 | 替代 |
|------|------|
| 兜底 | 回退 / 降级 / 防线 / 把关 / 拦下来；「兜底页」→「降级页」 |
| 铁证 | 实测 / 日志为证 / 数据摆在面前 |
| 赋能 | 帮 X 做成什么（具体动作） |
| 闭环 | 描述具体回路才留；泛指删 |
| 抓手 | 具体手段 / 方法 |
| 打通 | 连上 / 对接 |
| 对齐 | 统一 / 说清楚（工程语境下可留） |
| 拉通 | 协调（比「对齐」更虚，删） |
| 洞察 | 发现 / 结论 |
| 沉淀 | 攒下来 / 积累（具体宾语才留） |
| 降本增效 | 从 X 天降到 Y 小时 |
| 底层逻辑 [L2] | 原理（讲原理时可留；作「底层逻辑是这样的」装腔删） |
| 全生命周期 | 从建到删 / 全程 |
| 技术底座 | 基础设施 / 底层 |

## C. 空洞强调词

| 禁词 | 替代 |
|------|------|
| 至关重要 | 具体影响 |
| 不可或缺 | 没有它会怎样 |
| 意义深远 | 具体收益 |
| 真正的（多数） | 删（「真正的需求/瓶颈」这类有实质才留） |
| 恰恰 | 删 |
| 核心在于 | 删或换「关键是」 |
| 终极 | 删 |
| 护城河 | 优势 |
| 分水岭 | 标志 |
| 定时炸弹 | 隐患 |
| 本质 / 本质上 [L2] | 名词「问题的本质」可留；空洞副词「本质上…」删或换「原理」 |
| 澄清 [L2] | 正常动词「澄清事实」可留；铺垫「需要澄清的是 / 澄清一下」删 |
| 真相 [L2] | 普通名词「事件真相」可留；戏剧化「真相是… / 揭开真相」删 |

## D. 套话开场（删掉，直接进入内容）

- 综上所述 / 由此可见 / 不难看出
- 值得注意的是 / 值得一提的是 / 需要指出的是
- 不难发现 / 毋庸置疑 / 众所周知 / 不言而喻 / 诚然
- 在…的今天 / 在…的背景下 / 随着…的发展
- 在当今这个快节奏的时代 / 在这个信息爆炸的时代
- 「先X」口语开场：先泼盆冷水 / 先给大家 / 先聊聊 / 先问一句（删掉直接进内容）
- 自问自答设问句：key 哪来？/ 怎么用？/ 它是什么？（改直接陈述）

## E. 套话收尾（删掉，让内容自然结束）

- 以上就是…的全部内容
- 希望对你有帮助 / 希望本文对您有所帮助
- 你学会了吗
- 随着 AI 不断进化 / 未来可期（为结尾而结尾）

## G. 句式红线（见 SKILL.md 行为规范）

- 「不是 A，而是 B」排比（AI 句型第一名）
- 三连排比 / 任意凑排比（为对仗而对仗、为排比而排比，砍到最有力的一个）
- 破折号每篇 >2
- 连续 3+ 处冒号
- 每节加粗 >2 处
- 无意义类比 / 比喻（喻体和本体无实质关联，只为装深度；见 de-ai-patterns.md）

## H. 戏剧化 / 煽情用词（L2 慎用）

AI 特别爱把技术叙述写成「揭秘真相」的戏。这类词删掉戏剧外衣，换成具体动作。

| 禁词 | 替代 |
|------|------|
| 撕开（撕开真相 / 撕开面具）[L2] | 换具体动作，删戏剧化外衣 |
| 揭开面纱 / 戳破 / 剥开 [L2] | 同上，直接说做了什么 |

## I. AI 口头禅 / 模糊表达（L2 慎用，2026-08-05 新增）

这些词本身能说，但 AI 爱拿它们当「模糊指代」和「装精炼」的口头禅。命中只提示不阻断，人工判断：有具体所指才留，泛指就换。

| 词 | 替代 |
|------|------|
| 一件事 / 一件小事 [L2] | 换成具体所指：一次变更 / 一个目标 / 一个功能。「两件事」若后文有明确展开可留（作为观点锚点），泛泛的「一件事」一律具体化 |
| 一句话 [L2] | 「一句话说清 / 一句话总结」是 AI 口头禅，直接说，或改「核心分工是」 |
| 踩一遍 / 踩坑 [L2] | 换「重新走一遍 / 再犯一次 / 从头再来」 |
