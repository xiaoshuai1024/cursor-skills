# post-publish-ops 视频发布后运营

## 定位与边界

发布完成的定义 = `link-map pub_video.results` 四平台齐全（video-generation skill 发布确认口径）。本 skill 是发布完成之后一切运营动作的**统一入口**，只认领既有 skill 未覆盖的部分：

- **本 skill 拥有**：发布后时间线总览（下节）+ 新运营位——主页置顶作品位、B站动态/弹幕、B站稿件编辑面、私信承接、平台官方活动（免费）、视频号×公众号联动。
- **引用不重复**（细则单一事实源在各自 skill，本 skill 只做索引）：
  - 评论承接（24-96h 分诊逐条确认）→ comment-auto-reply skill（`make comment-reply`）
  - 合集转化钩子与合集粒度数据 → video-generation `references/publishing.md`「合集数据与转化定规」（openspec collection-data-conversion）
  - 发布复查三层处置细则 → publishing.md「发布后复查闭环」
  - 数据回流与回看 → video-analytics / wechat-analytics skill（`make analytics*`）
  - 变现与门槛 → `make analytics-revenue`（monetize-report）
  - 作品管理操作（delete/status/find/works）→ `ops` 统一入口（openspec platform-ops-toolkit）
- 图文笔记已退役（2026-08-30），本 skill 只管视频。

## 硬定规（2026-08-31 用户定规，openspec post-publish-ops-explore Phase 2）

1. **不做直播**：重投入，永久排除，任何会话不得排期或提案。
2. **不投流**：DOU+ / 快手粉条 / 视频号加热等一切付费加热一律不做（零预算）。平台活动中心的**免费**活动/任务不受此限。
3. **其余发布后运营点全做**：主页置顶 / B站动态 / 稿件编辑 / 弹幕 / 私信 / 免费活动 / 公众号联动。缺工具的项按 platform-ops-toolkit 定规走 ops 表登记，**禁止另起新脚本**。
4. **风控纪律**：实查与操作全部手动触发、一次一个平台、先看 `make pub-status` 避开风控冷却；平台侧采集永不挂无人值守定时（发布红线 9）。
5. **只读先行**：新运营位先只读实查（截图 + XHR 留证，留证落 `scripts/pub/vendor/logs/post_publish_explore/`），写操作逐个立项、走必问门禁后才实改。
